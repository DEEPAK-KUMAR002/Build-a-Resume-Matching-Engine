# Build-a-Resume-Matching-Engine

A Python-based Resume Matching Engine that uses TF-IDF and Cosine Similarity to match resumes with job descriptions.

## Features
- Skill normalization
- Resume skill deduplication
- TF-IDF vector generation
- Cosine similarity calculation
- Top 3 candidate ranking

## Technologies Used
- Python
- TF-IDF
- Cosine Similarity

## Run Project

bash
python resume_matching.py
